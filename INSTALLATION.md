# Установка VSX / VisionCore

## Требования

- Windows 11 x64;
- права администратора для установки и создания локальной службы;
- доступ компьютера к камерам по локальной сети;
- не менее 1 ГБ свободного места для программы и временных файлов установки;
- отдельный запас места для видеоархива — его размер зависит от числа камер,
  качества потока и режима записи;
- видеокарта необязательна: при отсутствии подходящего ускорения программа
  использует процессор.

## Перед установкой

1. Откройте нужный выпуск в разделе **GitHub Releases**.
2. Скачайте из одного и того же Release:
   - `install.exe`;
   - `install.sha256`.
3. Проверьте SHA-256 установщика.

Командная строка Windows:

```bat
certutil -hashfile install.exe SHA256
```

PowerShell:

```powershell
Get-FileHash -Algorithm SHA256 .\install.exe
```

Полученное значение должно совпадать со значением в:

```text
install.sha256
```

GitHub также отображает рассчитанную SHA-256 рядом с `install.exe`
в разделе **Assets** выпуска.

Не устанавливайте файл, если значения отличаются.

> `install.sha256` относится только к установщику из того же Release.
> Не используйте файл контрольной суммы от другой версии.

Установщик пока не подписан цифровым сертификатом Authenticode.

Windows может показать предупреждение о неизвестном издателе.

Проверка SHA-256 подтверждает целостность скачанного файла, но не заменяет
будущую цифровую подпись.

## Обычная установка

1. Закройте ранее запущенный VSX / VisionCore.
2. Запустите `install.exe` от имени администратора.
3. Выберите русский язык.
4. Прочитайте лицензионное соглашение и установите флажок согласия.
   Без него установка не продолжится.
5. При необходимости выберите создание ярлыка на рабочем столе.
6. Разрешение в брандмауэре для автоматического поиска камер включайте только
   для доверенной частной сети. Этот пункт по умолчанию выключен.
   Ручное добавление камеры по адресу не требует включать поиск.
7. Дождитесь окончания установки и запустите программу.

Все необходимые компоненты и базовая локальная аналитика уже входят
в `install.exe`.

Во время установки интернет не нужен.

## Первый запуск

1. Создайте администратора.
   В программе нет стандартного логина, стандартного пароля или временного пароля.
2. Сохраните пароль администратора в безопасном месте.
3. Откройте «Архив» и выберите папку хранения.
4. Не используйте корень диска, сетевую папку или съёмный носитель,
   который может внезапно отключиться.
5. Откройте «Камеры» и добавьте первую камеру.
6. Убедитесь, что изображение стабильно в обычном и высоком качестве.
7. Только после проверки включайте нужный режим записи.
8. Запись и аналитика для новой камеры по умолчанию выключены.

### Ограничение резервного копирования в 0.1.16

В текущем тестовом кандидате полная резервная копия данных службы
ещё недоступна.

Копирование и восстановление доступны только для отдельного локального профиля.

Не проверяйте удаление программы на рабочей серверной конфигурации,
если необходимо сохранить её пользователей и настройки.

## Обновление существующей установки

Установщик умеет закрыть компоненты VSX и обновить файлы программы.

Архив и рабочие данные хранятся отдельно и при обычном обновлении
не должны удаляться.

Для рабочей установки используйте **обновление поверх**, а не удаление
старой версии с последующей новой установкой.

Прежняя сборка 0.1.15 проверена двумя последовательными установками
без перезагрузки.

Это не является подтверждением полного цикла для тестового кандидата 0.1.16.

Если старые файлы службы имеют повреждённые права, установщик восстанавливает
доступ только внутри локальной папки VSX и не удаляет её содержимое.

Если Windows сообщает, что служба ещё занята:

1. завершите открытые окна VSX;
2. дождитесь окончания предыдущего удаления или установки;
3. повторите установку один раз от имени администратора;
4. перезагружайте Windows только при явном сообщении самой Windows
   о незавершённой системной операции.

Не запускайте несколько установщиков одновременно.

Не удаляйте вручную:

```text
C:\ProgramData\VisionCore
```

В этой папке могут находиться рабочие данные службы.

## Удаление

**Для рабочей установки с сервером пока не используйте удаление как способ
обновления.**

Полное резервное копирование пользователей и настроек службы ещё не готово.

Локальная копия интерфейса его не заменяет.

В 0.1.16 создание и восстановление неполной копии в серверном режиме
отключены с предупреждением.

Обновление поверх предназначено для сохранения данных.

Перед удалением создайте доступную резервную копию в папке вне данных VSX,
например:

- на другом диске;
- в папке «Документы».

Затем удалите VSX / VisionCore через:

**Параметры → Приложения → Установленные приложения**

и подтвердите предупреждение.

Деинсталлятор очищает:

- общие данные VSX;
- данные текущего профиля Windows;
- пользователей;
- сохранённые пароли;
- камеры;
- раскладки;
- правила записи;
- настройки аналитики.

Другие профили Windows очищаются при первом запуске новой установки
под каждым из них, а не немедленно во время удаления.

Не удаляются:

- видеозаписи;
- экспортированные материалы;
- готовые внешние резервные копии.

После следующей установки создаётся новая установка без стандартного
логина и пароля.

Администратора необходимо создать заново.

Восстановление пользователей службы из резервной копии станет доступно
после завершения полного серверного резервного копирования.

## Тихая установка для администратора

Лицензию необходимо принять явно:

```bat
install.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /ACCEPTEULA=YES
```

Тихая установка не создаёт пользователей автоматически.

Единственный администратор всё равно создаётся при первом осознанном
запуске программы.

## Тихое удаление

Для тихого удаления требуется отдельное подтверждение очистки данных:

```bat
"C:\Program Files\VSX VisionCore\unins000.exe" /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /PURGEUSERDATA=YES
```

Используйте этот режим только если последствия удаления данных понятны
и необходимые сведения предварительно сохранены.
