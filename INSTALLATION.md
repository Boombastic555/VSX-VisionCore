# Установка VSX / VisionCore

## Требования

- Windows 11 x64;
- права администратора для установки и создания локальной службы;
- доступ компьютера к камерам по локальной сети;
- не менее 1 ГБ свободного места для программы и временных файлов установки;
- отдельный запас места для видеоархива — его размер зависит от числа камер,
  качества потока и режима записи;
- видеокарта необязательна: при отсутствии подходящего ускорения программа
  использует процессор.

## Перед установкой

1. Скачайте рядом `install.exe` и `install.sha256`.
2. Проверьте SHA-256:

   ```bat
   certutil -hashfile install.exe SHA256
   ```

3. Для сборки 0.1.15 от 1 сентября 2026 г. ожидается:

   ```text
   78458DD15B600EA09DB0FC846D17D4E1BA2EEEED5BF5D6241484CC8AC1E013ED
   ```

4. Не устанавливайте файл, если сумма отличается.

Установщик пока не подписан цифровым сертификатом. Windows может показать
предупреждение о неизвестном издателе. Проверка SHA-256 подтверждает целостность
именно этой сборки, но не заменяет будущую цифровую подпись.

## Обычная установка

1. Закройте ранее запущенный VSX / VisionCore.
2. Запустите `install.exe` от имени администратора.
3. Выберите русский язык.
4. Прочитайте лицензионное соглашение и установите флажок согласия. Без него
   установка не продолжится.
5. При необходимости выберите ярлык на рабочем столе.
6. Разрешение в брандмауэре для автоматического поиска камер включайте только
   для доверенной частной сети. Этот пункт по умолчанию выключен. Ручное
   добавление камеры по адресу не требует включать поиск.
7. Дождитесь окончания установки и запустите программу.

Все необходимые компоненты и базовая локальная аналитика уже входят в
`install.exe`; во время установки интернет не нужен.

## Первый запуск

1. Создайте администратора. В программе нет стандартного логина, стандартного
   пароля или временного пароля.
2. Сохраните пароль администратора в безопасном месте.
3. Откройте «Архив» и выберите папку хранения. Не используйте корень диска,
   сетевую папку или съёмный носитель, который может внезапно отключиться.
4. Откройте «Камеры» и добавьте первую камеру.
5. Убедитесь, что изображение стабильно в обычном и высоком качестве.
6. Только после проверки включайте нужный режим записи. Запись и аналитика для
   новой камеры по умолчанию выключены.
7. В «Настройки» создайте резервную копию начальной конфигурации.

## Обновление существующей установки

Установщик умеет закрыть компоненты VSX и обновить файлы программы. Архив и
рабочие данные хранятся отдельно и при обычном обновлении не удаляются. Перед
обновлением всё равно рекомендуется создать резервную копию.

Если Windows сообщает, что служба ещё удаляется или занята:

1. завершите открытые окна VSX;
2. дождитесь окончания предыдущего удаления или установки;
3. перезагрузите Windows;
4. повторите установку один раз от имени администратора.

Не запускайте несколько установщиков одновременно.

## Удаление

Удалите VSX / VisionCore через «Параметры → Приложения → Установленные
приложения». Удаление программы намеренно не стирает записи, настройки и
резервные копии. Это защищает архив от случайной потери.

Если нужен полностью чистый компьютер, сначала сделайте резервную копию, затем
отдельно проверьте и удалите оставшиеся данные только вручную. Не удаляйте папку
архива, пока не убедитесь, что записи больше не нужны.

## Тихая установка для администратора

Лицензию необходимо принять явно:

```bat
install.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /ACCEPTEULA=YES
```

Такой режим не создаёт пользователей автоматически. Единственный администратор
всё равно создаётся при первом осознанном запуске программы.
