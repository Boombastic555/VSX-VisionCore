# VSX / VisionCore

![VSX / VisionCore](vsx.png)

VSX / VisionCore — локальная программа видеонаблюдения для Windows 11 x64.

Она показывает камеры в общей сетке и на видеостенах, ведёт архив, принимает
события и выполняет аналитику на этом компьютере.

Облачная учётная запись не нужна: видео, настройки и отчёты не отправляются
во внешние сервисы.

Текущая версия: **0.1.15**.

Это предварительная инженерная сборка для локальной проверки.
Перед использованием на ответственном объекте ознакомьтесь с
[известными ограничениями](KNOWN_LIMITATIONS.md).

## Что уже работает

- до 128 камер в каталоге и раскладке;
- обычные сетки, варианты «1 большая + 5» и «1 большая + 12», а также
  произвольное число ячеек;
- несколько мониторов и отдельные окна видеостены;
- перетаскивание камер, открытие двойным щелчком и полноэкранный режим;
- ручное добавление по ссылке `rtsp://...` и локальный поиск совместимых камер;
- автоматический поиск дополнительного потока, если камера его предоставляет;
- автоматическое восстановление связи и выбор подходящего способа передачи;
- запись для каждой камеры отдельно:
  - постоянная;
  - по расписанию;
  - при движении;
  - по событиям;
- запись по умолчанию выключена;
- календарь архива;
- полоса времени;
- покадровый просмотр;
- снимки;
- сохранение выбранного видео;
- события от совместимых камер и локальной аналитики;
- обнаружение движения, людей, автомобилей и животных;
- аналитика по умолчанию выключена и включается отдельно для нужных камер;
- автоматический выбор доступного ускорения с обязательной резервной работой
  на процессоре;
- один администратор;
- операторы с доступом к архиву;
- пользователи только для просмотра;
- для пользователя только просмотра пароль можно не задавать;
- локальные резервные копии настроек и восстановление;
- локальные отчёты для диагностики без отправки данных в интернет.

Подробный список возможностей:

## Быстрый старт

1. Откройте раздел **Releases**.
2. Выберите нужную версию VSX / VisionCore.
3. Скачайте из одного и того же выпуска:
   - `install.exe`;
   - `install.sha256`.
4. Проверьте контрольную сумму установщика.
5. Запустите `install.exe` от имени администратора.
6. Прочитайте и примите лицензионное соглашение.
7. При первом запуске создайте единственного администратора — готового логина
   или пароля в установщике нет.
8. Выберите локальную папку для архива.
9. Откройте «Камеры», введите адрес, логин и пароль, проверьте подключение
   и перетащите камеру в сетку.
