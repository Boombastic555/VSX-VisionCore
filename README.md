# VSX / VisionCore

![VSX / VisionCore](vsx.png)

VSX / VisionCore — локальная программа видеонаблюдения для Windows 11 x64.
Она показывает камеры в общей сетке и на видеостенах, ведёт архив, принимает
события и выполняет аналитику на этом компьютере. Облачная учётная запись не
нужна: видео, настройки и отчёты не отправляются во внешние сервисы.

Текущая версия: **0.1.15**. Это предварительная инженерная сборка для локальной
проверки. Перед использованием на ответственном объекте ознакомьтесь с
[известными ограничениями](KNOWN_LIMITATIONS.md).

## Что уже работает

- до 128 камер в каталоге и раскладке;
- обычные сетки, варианты «1 большая + 5» и «1 большая + 12», а также
  произвольное число ячеек;
- несколько мониторов и отдельные окна видеостены;
- перетаскивание камер, открытие двойным щелчком и полноэкранный режим;
- ручное добавление по ссылке `rtsp://...` и локальный поиск совместимых камер;
- автоматический поиск дополнительного потока, если камера его предоставляет;
- автоматическое восстановление связи и выбор подходящего способа передачи;
- запись для каждой камеры отдельно: постоянная, по расписанию, при движении и
  по событиям; по умолчанию запись выключена;
- календарь архива, полоса времени, покадровый просмотр, снимки и сохранение
  выбранного видео;
- события от совместимых камер и от локальной аналитики;
- обнаружение движения, людей, автомобилей и животных; аналитика по умолчанию
  выключена и включается отдельно для нужных камер;
- автоматический выбор доступного ускорения с обязательной резервной работой на
  процессоре;
- один администратор, операторы с доступом к архиву и пользователи только для
  просмотра; для пользователя только просмотра пароль можно не задавать;
- локальные резервные копии настроек и восстановление;
- локальные отчёты для диагностики без отправки данных в интернет.

Подробный список: [CURRENT_FEATURES.md](CURRENT_FEATURES.md).

## Быстрый старт

1. Скачайте из раздела Releases файлы `install.exe` и `install.sha256`.
2. Проверьте контрольную сумму установщика.
3. Запустите `install.exe` от имени администратора.
4. Прочитайте и примите лицензионное соглашение.
5. При первом запуске создайте единственного администратора — готового логина
   или пароля в установщике нет.
6. Выберите локальную папку для архива.
7. Откройте «Камеры», введите адрес, логин и пароль, проверьте подключение и
   перетащите камеру в сетку.

Полная инструкция: [INSTALLATION.md](INSTALLATION.md) и
[USER_GUIDE.md](USER_GUIDE.md).

## Проверка скачанного файла

Ожидаемая SHA-256 для установщика этой сборки:

```text
f184f34ba545a4c96e3c1cc51f60c940b732561e65f2179ee85919f9f5896d18
```

PowerShell:

```powershell
Get-FileHash -Algorithm SHA256 .\install.exe
```

Командная строка Windows:

```bat
certutil -hashfile install.exe SHA256
```

Если значение отличается, файл нельзя устанавливать.

## Конфиденциальность

- штатная работа программы полностью локальная;
- установщик не содержит камер, записей, пользовательских настроек или готовых
  учётных записей с компьютера разработчика;
- доступ через брандмауэр для поиска камер предлагается отдельно и по умолчанию
  выключен;
- обновления выбираются администратором из локального файла — программа сама не
  ищет и не скачивает их;
- технический отчёт создаётся локально и передаётся только самим пользователем.

## Статус выпуска

Состав офлайн-пакета, лицензия, фирменная иконка, резервная работа аналитики на
процессоре и контрольная сумма установщика проверены автоматически. Эта сборка
пока не подписана цифровым сертификатом и ещё не прошла окончательную проверку
установки на отдельной чистой Windows, длительную нагрузку со 128 реальными
камерами и полный многомониторный прогон. Поэтому GitHub Release следует
пометить как **Pre-release**.
