# VSX / VisionCore

![VSX / VisionCore](vsx.png)

VSX / VisionCore — программа видеонаблюдения для Windows 11 x64.

Просмотр камер, запись и воспроизведение архива, события, видеоаналитика и
видеостены объединены в одном интерфейсе.

В текущей версии просмотр, хранение записей и обработка видео выполняются на
компьютере с установленной программой. Облачные сервисы для работы не требуются;
установка и штатная работа не требуют интернета.

Текущая версия: **0.1.16**.

Это тестовый кандидат от 4 сентября 2026 г., не прошедший полную приёмку.
Полная резервная копия сервера ещё не готова: не удаляйте рабочую установку
ради обновления.

Перед использованием ознакомьтесь с
[известными ограничениями](KNOWN_LIMITATIONS.md).

## Что уже работает

- до 128 камер в каталоге и раскладке;
- обычные сетки, варианты «1 большая + 5» и «1 большая + 12», а также
  произвольное число ячеек;
- несколько мониторов и отдельные окна видеостены;
- перетаскивание камер, открытие двойным щелчком и полноэкранный режим;
- ручное добавление по ссылке `rtsp://...` и локальный поиск совместимых камер;
- автоматический поиск дополнительного потока, если камера его предоставляет;
- автоматическое восстановление связи и выбор подходящего способа передачи;
- запись для каждой камеры отдельно:
  - постоянная;
  - по расписанию;
  - при движении;
  - по событиям;
- запись по умолчанию выключена;
- календарь архива;
- полоса времени;
- покадровый просмотр;
- снимки;
- сохранение выбранного видео;
- события от совместимых камер и локальной аналитики;
- обнаружение движения, людей, автомобилей и животных;
- аналитика по умолчанию выключена и включается отдельно для нужных камер;
- автоматический выбор доступного ускорения с обязательной резервной работой
  на процессоре;
- один администратор;
- операторы с доступом к архиву;
- пользователи только для просмотра;
- для пользователя только просмотра пароль можно не задавать;
- резервные копии отдельного локального профиля;
- локальные отчёты для диагностики без отправки данных в интернет.

## Планы развития

Планируется защищённый удалённый доступ через интернет с индивидуальными
правами пользователей на камеры, архив и настройки.

В текущую версию эта возможность ещё не входит.

Удалённый доступ не предполагает обязательного облачного хранения:
записи смогут оставаться на вашем сервере.

## Скачать

Готовые установщики публикуются в разделе **Releases**.

Для каждого выпуска скачивайте из одного и того же Release два файла:

- `install.exe` — автономный установщик;
- `install.sha256` — контрольная сумма именно этого установщика.

Не используйте `install.sha256` от другой версии программы.

## Быстрый старт

1. Откройте раздел **Releases**.
2. Выберите нужную версию VSX / VisionCore.
3. Скачайте `install.exe` и `install.sha256` из одного выпуска.
4. Проверьте контрольную сумму установщика.
5. Запустите `install.exe` от имени администратора.
6. Прочитайте и примите лицензионное соглашение.
7. При первом запуске создайте единственного администратора — готового логина
   или пароля в установщике нет.
8. Выберите локальную папку для архива.
9. Откройте «Камеры», введите адрес, логин и пароль, проверьте подключение
   и перетащите камеру в сетку.

## Проверка скачанного файла

Каждый GitHub Release содержит файл:

```text
install.sha256
```

Он относится только к `install.exe` из этого же выпуска.

### PowerShell

```powershell
Get-FileHash -Algorithm SHA256 .\install.exe
```

### Командная строка Windows

```bat
certutil -hashfile install.exe SHA256
```

Полученное значение должно совпадать со значением в `install.sha256`.

GitHub также отображает рассчитанный SHA-256 рядом с `install.exe`
в разделе **Assets** выпуска.

Таким образом, должны совпадать:

```text
install.exe
    │
    ├── SHA-256, рассчитанный на вашем компьютере
    ├── значение из install.sha256
    └── SHA-256, отображаемый GitHub
```

Регистр букв в SHA-256 значения не имеет.

Если контрольные суммы отличаются, файл устанавливать нельзя.

> SHA-256 меняется при каждой пересборке `install.exe`.
> Всегда используйте `install.exe` и `install.sha256` из одного Release.

## Требования

- Windows 11 x64;
- права администратора для установки и создания локальной службы;
- доступ компьютера к камерам по локальной сети;
- не менее 1 ГБ свободного места для программы и временных файлов установки;
- отдельный запас места для видеоархива;
- видеокарта необязательна.

Размер архива зависит от количества камер, качества потока, битрейта,
частоты кадров, режима записи и срока хранения.

При отсутствии подходящего аппаратного ускорения программа использует процессор.

## Запись и архив

Запись новой камеры по умолчанию выключена.

Для каждой камеры отдельно можно настроить:

- постоянную запись;
- недельное расписание;
- запись при движении;
- запись по событиям камеры или аналитики.

Запись ведёт локальная служба и не зависит от того, находится ли камера
в открытой сетке.

Архив предоставляет:

- календарь дней с записями;
- поиск периода;
- выбор одной или нескольких камер;
- полосу времени;
- переход к выбранному времени;
- изменение скорости воспроизведения;
- звук;
- покадровый просмотр;
- снимки JPEG/PNG;
- экспорт видео MP4/MKV;
- ZIP-пакет со списком контрольных сумм.

## Локальная аналитика

Для каждой камеры отдельно можно включить:

- обнаружение движения;
- распознавание объектов;
- людей;
- автомобили;
- животных.

Аналитика по умолчанию выключена.

Программа автоматически выбирает доступное ускорение и при необходимости
продолжает работу на процессоре.

Встроенная локальная модель входит в офлайн-установщик и не требует
скачивания во время штатной работы.

[CURRENT_FEATURES.md](CURRENT_FEATURES.md).

## Пользователи

В программе предусмотрены три роли.

| Роль | Возможности | Пароль |
| --- | --- | --- |
| Администратор | Все функции, настройки и управление пользователями | Обязателен |
| Оператор | Просмотр, архив, события, снимки и сохранение видео | Обязателен |
| Пользователь | Только просмотр камер | Можно не задавать |

Администратор только один.

Он создаётся при первом запуске программы.

Готовых логинов, паролей или временных учётных записей установщик
не содержит.

## Резервные копии

В версии 0.1.16 копирование и восстановление доступны только для отдельного
локального профиля.

Полная резервная копия данных службы пока не реализована.

Это означает, что локальная копия интерфейса не сохраняет полностью:

- серверных пользователей;
- все настройки службы;
- машинные секреты.

В серверном режиме создание и восстановление неполной копии отключены
с предупреждением.

**Не удаляйте рабочую серверную установку, если необходимо сохранить
её пользователей и настройки.**

Обновление поверх существующей установки предназначено для сохранения данных.

Подробнее:
[KNOWN_LIMITATIONS.md](KNOWN_LIMITATIONS.md).

## Конфиденциальность

- записи хранятся на вашем компьютере;
- обработка видео выполняется локально;
- облачная учётная запись для штатной работы не требуется;
- установщик не содержит камер, записей, пользовательских настроек или готовых
  учётных записей с компьютера разработчика;
- доступ через брандмауэр для автоматического поиска камер предлагается отдельно
  и по умолчанию выключен;
- обновления выбираются администратором из локального файла;
- программа сама не ищет и не скачивает обновления из интернета;
- технический отчёт создаётся локально и передаётся только самим пользователем.

## Обновления

Обновление поверх существующей установки сохраняет настройки.

Не используйте удаление программы как обычный способ обновления рабочей
серверной установки, пока полное серверное резервное копирование не завершено.

Каждый новый установщик имеет собственную SHA-256.

Для каждой версии используйте только пару:

```text
install.exe
install.sha256
```

из одного и того же GitHub Release.

## Статус текущего выпуска

Версия **0.1.16** является тестовым кандидатом и должна публиковаться как
**Pre-release**.

Для кандидата прошёл полный автоматический прогон:

```text
334 / 334
```

без ошибок и пропусков.

Также проверены:

- целевые тесты очистки, идентификатора установки, резервной копии и изоляции;
- правила установщика;
- отсутствие широкого доступа к данным службы;
- состав офлайн-пакета;
- необходимые исполняемые компоненты;
- лицензии;
- встроенная модель аналитики;
- резервная работа аналитики на процессоре;
- фирменная иконка;
- контрольная сумма готового установщика.

При этом текущая сборка пока не подписана цифровым сертификатом Authenticode.

Windows может показать предупреждение о неизвестном издателе.

Также ещё не завершены:

- полный цикл установки, перезагрузки, работы без входа пользователя,
  удаления и повторной установки на отдельной чистой Windows 11;
- полная резервная копия данных службы;
- длительная нагрузка со 128 реальными потоками;
- полный физический многомониторный прогон.

Поэтому текущий выпуск не следует считать стабильным промышленным релизом.
