# Краткое руководство пользователя

## Роли

В программе три понятные роли:

| Роль | Возможности | Пароль |
| --- | --- | --- |
| Администратор | Все функции, настройки и управление пользователями | Обязателен |
| Оператор | Просмотр, архив, события, снимки и сохранение видео | Обязателен |
| Пользователь | Только просмотр камер | Можно не задавать |

Администратор только один. Он создаётся при первом запуске и может добавить
любое необходимое количество операторов и пользователей. Отдельного входа для
архива или служб нет. Флажок «Запомнить вход на этом компьютере» можно включить
на экране входа; кнопка выхода удаляет запомнённый вход.

## Добавление камеры

1. Откройте «Камеры» и нажмите «Новая».
2. В первом окне введите понятное имя, адрес камеры, порт, логин и пароль.
3. Оставьте режим подключения автоматическим. Для ручной камеры можно сразу
   вставить полную ссылку, например:

   ```text
   rtsp://IP:554/live/12
   ```

   Логин и пароль безопаснее вводить в отдельных полях формы. Поддержка ссылок
   со встроенными данными входа сохранена для совместимости с готовыми адресами
   камер.
4. Поле «Обычное качество» можно оставить пустым. Программа попробует получить
   дополнительный поток автоматически; если камера его не отдаёт, будет
   использоваться первый поток.
5. Сохраните настройки. Расширенный поиск открывайте только тогда, когда обычное
   добавление не нашло совместимую камеру или требуется управление поворотом.
6. Перетащите карточку камеры в свободную ячейку. Двойной щелчок по карточке
   помещает её в первую свободную ячейку.

Если изображение не появилось, проверьте адрес, логин, пароль, порт и доступность
камеры из этой сети. В плитке появится понятное состояние и рекомендуемое
действие. Программа может автоматически менять способ передачи при сетевых
сбоях.

## Просмотр и видеостена

- Выберите раскладку и число ячеек от 1 до 128.
- Готовые варианты: обычная сетка, «1 большая + 5» и «1 большая + 12».
- Камеры можно переносить между ячейками перетаскиванием.
- Постоянно показывается только название камеры. Кнопки качества, записи,
  снимка и очистки появляются при наведении указателя.
- Двойной щелчок по плитке разворачивает выбранную камеру на всю область и
  временно включает высокое качество. Повторный двойной щелчок возвращает сетку.
- Кнопка «Полноэкранный режим» оставляет на экране только камеры. Выход — `Esc`.
- «Видеостена» открывает отдельное окно на выбранном мониторе. Камеры можно
  перетаскивать в него; двойной щелчок и `Esc` работают так же.

## Запись

Запись новой камеры выключена. Откройте «Архив», выберите камеру и нажмите
«Настроить запись».

Можно включить один или несколько режимов:

- постоянная запись;
- запись по расписанию;
- запись при движении;
- запись по событиям от камеры или аналитики.

Если выбран режим по расписанию, добавьте хотя бы один недельный интервал.
Сообщение «ожидание условий» означает, что политика включена, но сейчас нет
подходящего времени, движения или события. Для постоянной записи ожидания
условий быть не должно.

Запись ведёт локальная служба и не зависит от того, находится ли камера в
видимой сетке. Удаление камеры из сетки не удаляет архив.

## Просмотр архива

1. Откройте «Архив» и отметьте одну или несколько камер.
2. В разделе «Дни с записями» выберите день, где есть видео.
3. Нажмите «Открыть».
4. Нажмите «Пуск» или переместите полосу времени. Ползунок показывает реальное
   положение внутри выбранной записи и двигается во время воспроизведения.
5. Для точного поиска используйте «Кадр назад», «Кадр вперёд» и переход ко
   времени.
6. Через панель сохранения можно создать снимок, сохранить выбранное видео или
   подготовить ZIP с файлами проверки целостности.

Полноэкранный режим, открытый из архива, сохраняет контекст архива и не должен
переключать программу на текущую сетку камер.

## Аналитика и события

В «Аналитика» для каждой камеры отдельно можно включить:

- обнаружение движения;
- распознавание объектов;
- нужные категории: люди, автомобили и животные.

По умолчанию всё выключено. Включайте аналитику только там, где она нужна.
Программа сама выбирает доступное ускорение и при необходимости продолжает
работу на процессоре.

Администратор может добавить подготовленный локальный пакет распознавания через
«Добавить свои файлы…». Файлы сначала проверяются на этом компьютере. Обычная
модель произвольного формата не подключается без совместимого описания пакета.

События движения, аналитики и совместимых камер появляются во вкладке
«События». Событие может запускать запись только тогда, когда такой режим включён
для конкретной камеры.

## Время

В «Настройки» можно показывать время компьютера либо выбрать регион отображения.
Сами записи и события хранят точное единое время, а интерфейс переводит его в
выбранный регион. Синхронизацией часов занимается Windows; кнопка на странице
времени открывает системные настройки синхронизации.

## Резервная копия

Создавайте резервную копию после добавления камер, изменения пользователей и
важных настроек. Восстановление выполняйте только из собственного проверенного
файла. Установка на новый компьютер не переносит администратора автоматически:
новые пользователи создаются на новом компьютере либо восстанавливаются явной
операцией администратора.
